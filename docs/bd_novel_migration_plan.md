# BÐ-novel 至 BÐ-Studio 原作頁移植規劃

## 目標

將《第九次出生》第一部至第四部的 37 個公開章節整合到 BÐ-Studio 的原作頁與站內閱讀器。小說正文、卷別名稱、章節名稱與閱讀順序會保留；不搬移 BÐ-novel 的網站視覺、背景音樂、追蹤腳本、第三方嵌入內容或導覽樣式。

## 資訊架構

原作頁會保留 BÐ-Studio 現有的首屏與封面，並新增四部作品索引。讀者可選擇第一部至第四部，並以「閱讀本部」進入站內閱讀器。閱讀器採單一 `/read/` 靜態入口，透過 `?chapter=1` 至 `?chapter=30` 指定章節；這個做法可在 GitHub Pages 上直接刷新與分享連結。

## 資料模型

每一部小說是一個獨立的延遲載入 TypeScript 資料模組，包含卷別資料與該部所有章節正文。共用索引檔只存卷別、章節名稱、章節編號與狀態；閱讀器只會下載讀者正在閱讀的那一部內容，以避免把 30 章正文全部納入首頁的初始載入。

## 導覽規則

閱讀器提供四部目錄、章節清單、上一章／下一章、返回原作頁與閱讀進度。當讀者跨越卷別邊界時，系統會自動載入下一部資料。所有正文顯示為純文字段落，不攜帶來源站原始 HTML、樣式、腳本或外部連結。

## SEO 與發布

`/read/` 會被靜態產生並使用原作專屬中繼資料。原作頁提供指向站內閱讀器的標準連結；BÐ-novel 原站可繼續存在，但 BÐ-Studio 成為主導覽的閱讀入口。

## 發布驗證

2026-08-25 已確認公開原作頁列出四部小說、37 個章節與各部站內閱讀入口。`/read/?chapter=37` 已能顯示第四部《第一次出生》的最終章〈第九次出生〉完整正文，並提供上一章及返回目錄導覽。閱讀內容依卷別採延遲載入資料模組，避免將全部正文併入原作首頁的初始資源。
